# 📚 LUC1D's Aidoku Sources

Premium manga sources for Aidoku with advanced features.

## 🚀 Quick Start

### Option 1: One-Click Install (Recommended)

**Click here to add sources to Aidoku:**

### ➡️ [**ADD TO AIDOKU**](https://luc1ddream.github.io/luc1d-aidoku-sources/add.html) ⬅️

The link will automatically open Aidoku and add all sources.

---

### Option 2: Manual Installation

If the automatic link doesn't work, add this URL manually in Aidoku:

```
https://luc1ddream.github.io/luc1d-aidoku-sources/index.json
```

**Steps:**
1. Open **Aidoku** app
2. Go to **Browse** → **Sources**
3. Tap the **+** button (top right)
4. Paste the URL above
5. Done! 🎉

## ❓ FAQ

### What is this?

A custom source repository for the Aidoku manga reader app. These sources provide enhanced features not available in official sources.

### Is it safe?

Yes. All sources are open-source and built from the code in this repository. You can review the code yourself.

### How do I update sources?

Sources update automatically when you check for updates in Aidoku. New versions are pushed regularly.

### Something not working?

Open an issue on GitHub or contact the maintainer.
