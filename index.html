❓ What is this?

This is a custom source repository for the Aidoku manga reader app. It provides enhanced versions of popular manga sources with advanced features like premium chapter detection, unlock timers, and improved performance. All sources are open-source and regularly updated.

🔒 Is it safe?

Yes! All source code is publicly available on GitHub. You can review every line of code yourself. The sources are built using GitHub Actions with full transparency. No tracking, no ads, no data collection.
